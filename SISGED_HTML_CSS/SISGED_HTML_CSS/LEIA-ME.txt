SISGED - SITE ESTÁTICO (somente HTML + CSS)

Abra o arquivo index.html no navegador. Não há JavaScript, PHP, banco de dados, Laravel nem login.

Páginas: index.html, consulta.html, instrutores.html, informacoes.html
Estilos: css/style.css   |   Imagem: img/logo.png

Os dados (aulas, instrutores, turmas, matérias, salas) estão escritos diretamente nos arquivos HTML.
Para alterar, edite a tabela correspondente no HTML (em consulta.html, cada <tr> é uma aula;
os atributos data-* da linha são usados pelos filtros em CSS).

Observação: os filtros da consulta usam o seletor CSS :has(), suportado por Chrome, Edge, Safari
e Firefox atuais (a partir de 2023/2024).
