SISGED / NetNúcleo - VERSÃO ESTÁTICA (sem login, sem PHP, sem MySQL, sem servidor)

COMO USAR
  Abra o arquivo index.html direto no navegador. Não há tela de login: o site abre livre.
  Não precisa de Apache, XAMPP, Laravel ou banco de dados.

O QUE TEM
  - Consulta de aulas (filtros por data, período, turma, instrutor, matéria e situação)
  - Cadastro de aulas (com validação de conflito de horário)
  - Cadastro de instrutores

COMO FUNCIONA
  - public/db.js substitui os controllers PHP e o banco MySQL, iniciado com os dados do bancodedados.sql.
  - O que for cadastrado fica salvo no navegador (localStorage). Outro navegador/computador = dados iniciais.
  - Para voltar aos dados originais: link "Restaurar dados de demonstração" na página inicial.
  - Pode ser hospedado em qualquer hospedagem estática (GitHub Pages, Netlify etc.).
